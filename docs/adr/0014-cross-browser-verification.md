# 0014 — Human Safari/Firefox pass before v0.2

**Status:** Proposed

## Decision (proposed)
Before v0.2: a human walks every showcase page in Safari (macOS and iOS) and Firefox,
light and dark, with screenshots; findings become issues. Add WebKit and Firefox to the
Playwright a11y run where the harness allows (Playwright ships both).

## Consequences
- Closes the largest unverified risk in ADR 0010.
